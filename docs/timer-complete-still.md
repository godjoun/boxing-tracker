# 운동 완료 화면 — 스틸컷

## 문서 정보

- 소유: Boxing Tracker 프로젝트
- 독자: Product, UX, Frontend
- 읽는 시점: 타이머 완료 UI를 바꿀 때

## Decision

완료 화면의 주인공은 라운드 수다. EXP·대시보드 정보는 표면에 올리지 않는다.  
톤은 “해냈다!”가 아니라 “오늘도 벨은 울렸다.”다.

## 구성

1. ROUND COMPLETE
2. 닉네임 · 지역 (크레딧)
3. 라운드/세트 · 운동 시간
4. 슬로건
5. 날짜·시간·연속
6. N번째 벨 · 누적 시간
7. PUNCH ERA 브랜드 라인
8. CTA·보조 링크는 포스터 아래

## 검증

- 린트·테스트·빌드
- 실제 폰에서 타이머 완료 후 스크린샷 구도 확인
