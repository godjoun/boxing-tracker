# 짐 화면 구조

> UI 복제 금지. **흐름·자리만** 빌린다.  
> 제품: `docs/dojo.md` · 수익: `docs/monetization.md`

## 최상위 구조 (현재)

첫 화면은 **풀맵**이다.

| 자리 | 내용 |
|------|------|
| 상단 | 검색 · 문의 아이콘 · 카테고리 칩 **체육관 · 라이벌 · 찜 · 모임** |
| 왼쪽 플로팅 | 홈 (아이콘만, 검색 아래) |
| 하단 시트 (모바일) | 목록·인기 · 핀/행 선택 시 미리보기는 우측 패널 |
| 우측 패널 | 핀·카드 클릭 → 장소 미리보기·상세 (데스크톱 주 패널) |
| 더보기 메뉴 | 홈 · 찜 · 내 문의 · **명패 · 라이벌 카드** · 체육관 등록 · 관장 입점 |

> 카테고리는 칩 **한 줄만** 사용한다. 하단 독(발견·문의·모임·저장)은 제거했다.  
> 지도 앱 **흐름·자리**만 참고. 구글/네이버 UI·로고·타일 복제 금지. MANTLE 톤 유지.

**라이벌 카드 편집**은 짐 화면이 아니라 **명패(프로필)** 탭에서 한다.  
짐 화면 라이벌 레이어는 **지도 핀 + 우측 정보 + 관심/대화**만.

**모임**은 사람·시간을 맞추는 일정이며, 체육관 대여·체험·예약은 기존 문의 유형으로 유지한다. 메시지 알림 확장은 나중.

## 참고 앱에서 가져온 것

| 앱 | 빌린 구조 | 안 가져온 것 |
|----|-----------|--------------|
| **당근** 비즈프로필 | 찾기 → **가게 홈**(커버·소개·가격) → 문의·채팅 | 단골·쿠폰·후기 피드 |
| **플랩** | 장소/매치 카드 → **상세** → 신청(행동 1개) | 소셜 매치·레벨·구장 예약 풀스택 |
| **Boxing Network** | 짐/이벤트 **허브** + 문의·매칭은 다음 행동 | 팀 가입·bout sheet·코치 워크플로 |
| **더코너류** | 사용자가 **내 체육관**을 프로필에 연결 | 지금 전역 커뮤니티 피드 |

## 관 상세 = 가게 홈 (잠금)

한 장면: **커버 사진 · 관 이름 · 소개 · 위치 · 이용권 · 문의하기(또는 받은 문의)**.  
상세는 우측 패널에서 연다. 커뮤니티는 한 줄 자리만.

코드: `GymDetailPanel.jsx`

## 체육관 지도 — 보조 행동

| 행동 | 흐름 |
|------|------|
| **내 체육관으로 등록** | 지도 핀 → 상세 → 프로필 소속 저장 |
| **새 체육관 등록** | 없는 장소 제보 → 이름·주소·좌표 → 승인 대기 |
| **내 문의** | 보낸 문의 → 미리보기 → 대화 |
| **모임** | 모임 올리기 → 참가 신청 → 주최자·신청자 대화 |
| **관장 입점 관리** | 입점 신청·수정 · 승인 상태 · 받은 문의 |
| **라이벌 카드** | 명패 탭 → 공개/스펙 저장 → 짐 지도에 표시 |

SQL: `dojo_inquiry_chat.sql` + `dojo_inquiry_chat_inbox.sql`  
안 읽음 확장·푸시·Realtime은 나중.

연락처는 공개하지 않는다. 답장은 앱 대화가 기본.
