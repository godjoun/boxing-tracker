# Logs

## 목적

Logs는 날짜별 작업 일지다. 진행 중 발견한 관찰, 실수, 짧은 배움, 후속 확인 항목을 남긴다.

## 기록 방식

파일명은 `YYYY-MM-DD.md`를 사용한다. 기록은 짧고 사실 중심으로 쓴다.

```text
# YYYY-MM-DD

## 작업
- 무엇을 했는가

## 관찰
- 무엇을 확인했는가

## 실수와 배움
- 다음에는 어떻게 바꿀 것인가

## 후속
- 남은 확인 항목
```

## 경계

- Logs는 작업 일지이지 지식 저장소가 아니다.
- 제품·기술의 장기 결정과 그 이유는 `SDS/00_BRAIN/DECISIONS.md`가 원본이다.
- 일지에서 결정이 필요해지면 `DECISIONS.md`에 기록하고, Logs에는 해당 결정으로 연결한다.
- 프로젝트에만 유효한 기능 명세, 버그, 회의 내용은 프로젝트 `docs/`에 둔다.

반복되는 관찰은 Workflow, Template, Automation으로 승격해 시스템을 개선한다.
