## 1차의 한 줄 목표

**체육관에 갈 수 없는 날에도 사용자가 복싱을 시작하고, 완료하고, 그 기록을 다시 보게 한다.**
홈트 자체를 시장으로 검증하지 않는다. 체육관 밖에서도 복싱을 이어가려는 사람의 실제 행동을 검증한다.

## 메시지 계층 (1차)

표면에서만 말한다. LV/EXP·기능 나열은 뼈대다.

1. **초대** — ARE YOU READY?
2. **상황** — 체육관에 갈 수 없는 날에도 복싱은 계속된다.
3. **증거** — 라운드·시간·연속·포스터 카드 (숫자로 증명)
4. **축적** — 어디에서 했든 실제로 한 복싱은 내 이력으로 남는다.

2와 4는 제품 메시지 방향이다. 공식 대표 문구 **ARE YOU READY?**를 대체하는 새 슬로건으로 확정하지 않는다.

영문 악센트는 한국어 철학과 충돌하지 않게만:  
`I RULE THE ROUND.` / `LIFE GOES ON. SO DOES THE FIGHT.`

### 말하지 않음 (1차)

- 이름 뜻 풀이
- “AI 복싱 앱”, “게임처럼 키우는”, SSR·티어·가챠 톤
- 전국 커버·대기업 스포츠앱 비교
- 체육관을 대체한다는 표현
- “홈트 앱”만으로 제품을 좁히는 설명

| 2 | 체육관 밖에서도 복싱을 이어가고 싶은 사람 | 안내·드릴·타이머·자동 기록·프로필 축적 |
| 후속 | 체육관·교류·라이벌 연결이 필요한 사람 | 핵심 훈련 루프 검증 후 별도 판단 |

관객(팔로워)을 위한 SNS 앱이 아니다. **주인공이 자기 필름을 남기는 도구.**

## 어디에 어떻게 (채널 1차)

채널을 늘리지 않는다. **한 장면 = 한 포스트.**

| 채널 | 역할 | 빈도 감 |
|------|------|---------|
| 앱 내부 | 훈련 선택 · 완료 스틸컷 · 기록·프로필 | 제품이 메시지를 증명 |
| 인스타/숏폼 (선택) | 훈련 사진 + 필름감 + 슬로건 한 줄 | 주 1~2 · 과하지 않게 |
| 기존 복싱 수련자 인터뷰 | 체육관에 갈 수 없는 날의 행동·포기 이유 확인 | 초기 검증 |
| 카톡/지인 | 베타 링크 + 사용 상황 한 줄 | 테스트 초대 |

### 비주얼 우선순위 (마케팅·다크 필름)

1. 사용자 훈련 사진  
2. 필름 필터·그레인  
3. 타이포  
4. 포스터 카드  
5. 색 (버건디는 CTA·강조만)

라이트 랜딩·도구 화면은 **흰 무대 + 잉크**. 버건디로 배경을 채우지 않는다.

세계관은 **현대 복싱 70% / 전국시대의 긴장감·질감 30%**로 제한한다.
사무라이·칼·갑옷·일본 성·전통문양과 근거 없는 전투력·랭크는 사용하지 않는다.

## 초기 검증 질문과 성공 신호

1. 체육관에 갈 수 없는 날에도 운동하고 싶어 하는가?
2. 그때 무엇을 해야 할지 몰라 운동을 건너뛰는가?
3. PUNCH ERA를 통해 실제 훈련을 시작하는가?
4. 시작한 훈련을 완료하는가?
5. 완료 기록을 다시 확인하는가?
6. 며칠 뒤 다시 운동하는가?

“홈트 앱을 원하는가?”는 핵심 검증 질문이 아니다. 입점 수, 문의 수, 커뮤니티 활동도 현재 성공 기준으로 두지 않는다.

## 제품과의 맞춤 (지금 출시분)

이미 잠긴/올라간 표면을 1차 자산으로 쓴다.

- 입장: PUNCH ERA + ARE YOU READY? + 철학 한 줄
- 훈련: 4주 코스 · 기술 훈련 · 자유 복싱 · 러닝 · 타이머
- 링 완료: 스틸컷 (“오늘도 벨은 울렸다.”)  
- 축적: 기록 · 프로필 · 복싱 이력
- 보조: 현재 제공 중인 OSM 체육관 지도·검색

체육관 입점·협업·문의·DM·교류·라이벌·커뮤니티는 현재 핵심 출시·검증 범위에 넣지 않는다.

## 바로 할 일 (운영·카피만)

1. 체육관에 갈 수 없는 날의 상황과 기존 대처를 인터뷰한다.
2. 그 상황에서 PUNCH ERA로 훈련 시작·완료·기록 확인이 이어지는지 본다.
3. 며칠 뒤 같은 사용자가 다시 훈련하는지 확인한다.
4. 제품 설명은 사용 상황과 행동을 직접 말하고, 공식 슬로건은 그대로 유지한다.

카피·비주얼 시안을 깊게 여러 안으로 펼칠 때는 고성능 모델 세션으로 이어간다.
