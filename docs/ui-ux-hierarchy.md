# UI/UX 계층 개선 — 2026-08

> 소유: 프로젝트 `docs/`  
> 독자: 제품·디자인·프론트엔드 담당자  
> 사용하는 때: 기존 화면을 손볼 때, 새 기능을 추가하기 전

## 목적

기능을 늘리지 않고 기존 화면의 시선 흐름을 정리한다. 홈 첫 뷰에는 사용자가
지금 해야 할 행동과 오늘의 흔적만 두고, 도구·전체 기능은 더보기에서 찾게 한다.

### 출시 품질 판단 (2026-08-04 잠금)

1. 생각하지 않고 쓸 수 있는가?
2. 정보가 한눈에 들어오는가?
3. 한 화면 · 한 행동이 명확한가?
4. 불필요한 기능·정보는 없는가?

완성 우선: **커뮤니티** (`docs/community-ia.md` · `docs/community-ui.md`) → 홈·훈련·기록·전체·프로필·성장.  
Vision Loop: `훈련 → 기록 → 교류 → 프로필에 흔적 → 신뢰 → 새로운 교류 → 다시 훈련`.  
관↔관 본구현은 출시 후 (`docs/gym-exchange.md`).


## 화면 목적

| 화면 | 목적 |
|---|---|
| 온보딩 | 사용자가 링네임만 정하고 바로 앱을 시작하게 한다. |
| 홈 | 사용자가 3초 안에 운동을 시작하고, 오늘의 흔적을 확인하게 한다. |
| 훈련 | 사용자가 망설임 없이 라운드를 선택하고 시작하게 한다. |
| 타이머 진행 | 사용자가 시간과 현재 라운드에 집중하게 한다. |
| 운동 완료 | 사용자가 오늘의 성취와 서사를 느끼게 한다. |
| 기록 | 사용자가 운동 종류에 맞는 입력으로 빠르게 남기고 돌아보게 한다. |
| 성장 | 사용자가 자신의 커리어 구간과 다음 시즌 보상을 이해하게 한다. |
| 프로필 | 사용자가 복서 정체성·훈련 흔적·**교류의 흔적**으로 신뢰를 확인하게 한다. |
| 명패 | 사용자가 오늘의 훈련 장면을 증명하고 공유하게 한다. |
| 짐 / 커뮤니티 | 사용자가 다음 교류를 고르고, 관·사람·일정으로 들어가게 한다. (`community-ia.md`) |
| 전체 메뉴 | 사용자가 목적별 그룹에서 필요한 도구와 기능을 빠르게 찾게 한다. |

| 홈 | 오늘의 장면 | 레슨 열기 또는 훈련 시작 | 주간·통계·현황·캘린더 · 전체 기능은 전체 메뉴 |
| 훈련 | 오늘의 라운드 | 선택한 라운드 시작 | 직접 설정·기술·몸 만들기·콤보·성장 정보 |
| 타이머 완료 | 완료 스틸컷 | 인증 카드 만들기 | 다시 시작·홈·기록 이동 |
| 성장 | 현재 커리어 구간 | 다음 승급 목표 확인 | 월간 승급·전체 구간·칭호·혜택·업적 |

| 프로필 | 복서 정체성·훈련 흔적·**교류의 흔적** | 명패 · 이력 읽기 | 레벨·시즌 · 라이벌 카드는 접기 |
| 명패 만들기 | 큰 미리보기 | 사진·문구·스타일 → 저장 | 세부 정보(날짜·체육관·라운드)·공유 |
| 전체 메뉴 | 목적별 기능 그룹 | 선택한 기능으로 이동 | 기능 설명·해금 안내 |

## 표현 원칙

- 하단 내비는 `훈련 → 기록 → 홈 → 커뮤니티 → 전체`로 둔다. 홈은 가운데에 둔다.
- 주요 화면은 같은 좌우 여백과 카드 경계를 사용한다. 시각 레퍼런스의 모양보다
  정보 밀도와 계층을 적용하며, 공통 오버라이드는 `src/reference-layout.css`에서 관리한다.
- 홈의 오늘 장면은 기본 사진을 강제하지 않는다. 사용자는 우측 상단 사진 메뉴에서
  자신의 사진을 선택·교체·삭제할 수 있고, 사진이 없으면 브랜드 배경만 표시한다.
- 홈의 기본 순서는 `브랜드·인사 → 오늘의 장면(CTA) → 이번 주 7일 → 최근 기록 → 레벨`이다.
  첫 사용자는 `장면(CTA) → 시작 안내 3줄`만 먼저 보이고, 주간·최근·레벨은 기록이 생긴 뒤에 연다.
  기능 바로가기는 하단 내비와 전체 메뉴에 맡기며 홈에서 중복 노출하지 않는다.
- 라이트는 흰 무대와 잉크 텍스트를 기본으로 한다.
- 다크는 오일 블랙과 버건디 나이트를 무대로 한다.
- 버건디 `#8A2E2E`는 시작·저장·문의 같은 사용자 행동에만 쓴다.
- 레벨·EXP는 성장의 뼈대이며, 일상 화면의 주인공이 아니다.
- 성장 화면 안에서는 기존 레벨 구간을 커리어 리그로 설명한다. 리그는 경쟁·가챠가
  아니라 개인 훈련 기록의 구간표다.
- 월간 보너스는 해당 월에 훈련 기록이 있는 사용자가 그 달의 최고 리그를 기준으로
  영구 레벨을 받는다: 일반인 +1, 아마추어 +1, 세미프로 +2, 프로 +2,
  챔피언 +3, 레전드 +3. 현재 기기 로컬 저장이므로 계정 동기화 전에는
  브라우저·기기 간 이전되지 않는다.
- 리그 진입 혜택도 같은 경계를 쓴다: 아마추어 인증(LV16), 세미프로 카드(LV36),
  프로 인증(LV51), 챔피언 카드·명패(LV76), GOAT 카드·명예의
  전당(LV96).
- 성장 화면은 전체 티어표를 전면에 펼치지 않는다. 현재 커리어와 다음 큰 단계,
  각 구간의 레벨 범위를 먼저 보여주고, 전체 리그표는 접힌 보조 정보로 제공한다.
- 하단 내비는 현재 화면의 CTA보다 강하게 보이지 않는다.
- 홈에는 전체 메뉴와 같은 기능 목록을 두지 않는다. 링·짐·명패는 하단 내비,
  기록·기술·도구는 전체 메뉴에서 연다.
- 홈은 첫 사용자에게 「다음에 할 일」을 짧게 안내하고, 기록이 쌓이면
  오늘 CTA → 최근 기록만 먼저 보이게 한다.
- 375px에서 첫 사용 홈은 CTA와 시작 안내가, 이후 홈은 CTA와 최근 기록이
  거의 스크롤 없이 보인다.
- **버튼:** 화면당 메인 CTA는 하나만 버건디로 강조한다. 나머지는 Secondary
  (중립 테두리/배경) 또는 Text Button으로 낮춘다. 사용자가 “무엇을 눌러야
  하지?”라고 고민하지 않게 한다.
- **정보량:** 한 화면에 너무 많은 정보를 넣지 않는다. 한 번에 보여줄 핵심은
  다음 행동에 필요한 것만 두고, 나머지는 접기·다음 화면·Step으로 나눈다.
  사용자는 고민하지 않고 다음 행동을 고를 수 있어야 한다.
- **운동별 기록:** 새 기록은 복싱·러닝·웨이트·걷기 중 하나를 먼저 고른다.
  복싱은 라운드·시간, 러닝은 거리·시간·자동 페이스, 웨이트는 운동명·세트·무게,
  걷기는 시간·거리만 받는다. GPS 자동 측정과 Apple Health·Health Connect·
  Garmin 연동은 네이티브 앱 또는 외부 파트너 권한이 필요한 별도 단계다.

| 화면 | 메인 CTA | Secondary / Text |
|---|---|---|
| 홈 | 오늘 훈련 시작·레슨 열기 | 최근 기록, 링에서 더 보기, 백업 |
| 훈련 | 라운드 선택·시작 | 직접 설정, 기술, 몸 만들기, 콤보 |
| 운동 완료 | 인증 카드 만들기 | 다시 시작, 홈, 기록 |

### 정보량 적용

| 화면 | 항상 보이는 핵심 | 접거나 Step으로 미룬 것 |
|---|---|---|
| 홈 | 오늘 장면·CTA · (첫 사용: 시작 안내 3줄 / 이후: 최근 기록) | 상세 통계·캘린더는 접기 · 전체 기능은 하단 탭·전체 메뉴 |
| 훈련 | 라운드 선택·시작 | 성장 정보·도움말은 접기 |
| 성장 | 현재 구간·레벨 범위·다음 승급 목표 | 월간 승급·전체 6개 구간·수집 기록은 접기 |
| 기록 쓰기 | Step 1 운동 카테고리·핵심 수치 → 2 날짜·강도·컨디션 → 3 메모·저장 | 운동과 무관한 입력·목록 편집은 뒤로 물린다 |
| 짐 문의 | Step 1 종류 → 2 일정·상세 → 3 연락처·동의·전송 | 개인정보 안내·완료 화면은 별도 뷰 |

## 잠금 규칙 요약

1. 화면 목적을 먼저 정한다.
2. 한 화면에 시선 주인공은 하나다.
3. 구역 사이 여백을 넉넉히 둔다.
4. 메인 CTA는 화면당 하나다.
5. 정보량은 다음 행동에 필요한 것만 남긴다. 필요하면 Step으로 나눈다.

## 수동 확인

- 첫 사용자는 링네임을 입력한 뒤 별도 중복확인 없이 시작하기를 누를 수 있고,
  사용 중인 이름일 때만 같은 화면에서 오류를 확인한다.
- 375px에서 첫 사용 홈은 CTA·시작 안내가, 이후 홈은 CTA·최근 기록이
  거의 스크롤 없이 보인다.
- 홈 상세 통계는 「기록」 접기 안에만 있다.
- 첫 사용 안내의 링·짐 이동이 하단 탭과 같은 목적지로 간다.
- 전체 메뉴는 운동하기·나를 보기·함께하기·앱 관리의 2열 목적 그룹으로 보이고,
  각 기능은 한 번의 선택으로 기존 목적지에 이동한다.
- 프로필 첫 화면은 복서 정보·누적 라운드·링 위의 시간·연속 훈련·최근 기록과
  명패 만들기만 먼저 보여준다. 라이벌 카드는 현재 출시 범위에서 제외하며,
  Level 3 재착수 전에는 핵심 행동으로 노출하지 않는다.
- 홈의 미훈련·훈련 완료·진행 중 타이머·레슨 상태가 기존 목적지로 이동한다.
- 기록·기술·도구·테마·튜토리얼은 전체 메뉴에서 찾고 이동할 수 있다.
- 기록 쓰기 1→2→3 Step과 저장, 짐 문의 1→2→3 Step과 전송이 된다.
- 복싱·러닝·웨이트·걷기는 각자 필요한 입력만 보이고, 기존 타이머와 과거 기록은
  기존 이름·표시를 유지한다.
- 훈련 화면은 라운드 선택에 따라 시작 버튼이 바뀌고, 기술·몸 만들기·콤보는
  상단 메뉴에 한 번씩만 보인다. 프리셋 시작은 설정을 반복하지 않고 준비
  카운트다운으로 바로 이어지며, `직접 설정`만 타이머 설정 화면을 연다.
  성장 정보와 도움말은 처음에는 접혀 있다.
- 직접 설정 진입과 타이머 완료 후 카드 제작이 유지된다.
- 성장 첫 화면은 현재 구간·레벨 범위·다음 큰 구간만 보이고, 월간 승급·전체
  커리어 구간·수집 기록은 접힌 상태다. 전체 구간과 기존 상세 도감은 열 수 있다.
- 짐의 체육관 칩·핀·시트·상세·문의와 명패의 편집·스튜디오 흐름이 유지된다.
  라이벌 흐름은 프로토타입 기술 자산으로만 남기고 현재 출시 회귀 범위에서 제외한다.
- 짐은 위치 확보 후 도시 입점관 수를 보여주고, `내 주변`과 `전체 입점관` 목록을
  분리한다. 위치 거부 시 지역 검색으로 같은 흐름을 사용할 수 있다.
