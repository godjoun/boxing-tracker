# Case #001 — 모바일 짐 화면 하단 메뉴 겹침

## 문서 정보

- 소유: Boxing Tracker 프로젝트
- 독자: Product Strategist, UX Designer, Frontend Engineer
- 읽는 시점: 짐 지도 화면의 레이아웃·하단 행동을 변경하기 전

## Evidence

- 날짜: 2026-08-02
- 출처: 직접 사용자 피드백
- 대상 또는 표본: 사용자 1명
- 관찰 사실: 모바일 짐 화면에서 홈 버튼이 앱 하단 메뉴에 가려진다고 보고됨
- 한계: 기기·브라우저별 재현 범위는 아직 확인 전

## 문제

- 모바일 Gym 페이지에서 Home 버튼이 전역 Bottom Navigation에 가려진다.
- 사용자는 짐 지도에서 홈으로 돌아가거나 짐 전용 하단 행동을 선택할 수 있어야 한다.

## 원인

`is-edge-to-nav` 레이아웃이 지도 서비스를 전체 높이로 확장해, 전역 Bottom Navigation 높이를 고려하지 않았다.

## 해결 (갱신: 발견형 지도 UX)

- 지도가 화면의 주인공이 되도록 상단 검색창·칩을 지도 위에서 제거했다.
- 검색은 🔍 → Search Modal(최근 검색 · 추천 지역 · 지역 목록)에서만 한다.
- 시트 「필터」로 카테고리(체육관·라이벌·찜·모임) + 거리 반경 시트를 연다.
- peek 시 상단은 지도 포커스 모드(← · 내 위치 · 🔍)로 줄어든다.
- 짐 화면 전용 Home 버튼(side rail)을 제거하고, 지도 **내 위치** 버튼만 사용한다.
  (앱 하단 탭의 홈은 유지)
- peek는 Apple Maps식 Preview Card 1장, 핸들을 올리면 half/full 목록이 열린다.
- 개인 PT · 시설 필터는 입점 데이터 이후 (`docs/later.md`).
- 지도 서비스 높이에서 전역 Bottom Navigation 높이(`--app-nav-total`)를 제외한다.

## 완료 기준

- 모바일에서 지도가 가장 넓게 보이고, peek면 포커스 바, half면 「짐 찾기」 히어로가 보인다.
- 검색 모달·필터 시트·내 위치로 기존 찾기 흐름이 유지된다.
- peek Preview Card → 핸들 업 → 전체 목록이 된다.
- 데스크톱 사이드 패널·전역 하단 탭 동작이 유지된다.

## 검증 결과

- 구조 반영 완료. lint 통과.
- 실제 모바일에서 Preview Card·검색 모달·필터 시트·내 위치 최종 확인이 필요하다.
