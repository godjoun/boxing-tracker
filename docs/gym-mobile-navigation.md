# Case #001 — 모바일 짐 화면 하단 메뉴 겹침

## 문서 정보

- 소유: Boxing Tracker 프로젝트
- 독자: Product Strategist, UX Designer, Frontend Engineer
- 읽는 시점: 짐 지도 화면의 레이아웃·하단 행동을 변경하기 전

## Evidence

- 날짜: 2026-08-02
- 출처: 직접 사용자 피드백
- 대상 또는 표본: 사용자 1명
- 관찰 사실: 모바일 짐 화면에서 홈 버튼이 앱 하단 메뉴에 가려진다고 보고됨
- 한계: 기기·브라우저별 재현 범위는 아직 확인 전

## 문제

- 모바일 Gym 페이지에서 Home 버튼이 전역 Bottom Navigation에 가려진다.
- 사용자는 짐 지도에서 홈으로 돌아가거나 짐 전용 하단 행동을 선택할 수 있어야 한다.

## 원인

`is-edge-to-nav` 레이아웃이 지도 서비스를 전체 높이로 확장해, 전역 Bottom Navigation 높이를 고려하지 않았다.

## 해결

- 지도 서비스 높이에서 전역 Bottom Navigation 높이(`--app-nav-total`)를 제외했다.
- 홈·지도 바로가기(side rail)는 검색/칩 아래 **좌측 상단**으로 옮겼다.
- 카테고리는 칩 한 줄(`체육관 · 라이벌 · 찜 · 모임`)만 사용하고 하단 독을 제거했다.
- 모바일 결과는 `GymMapSheet` 목록으로 보고, 문의는 검색창 옆 아이콘으로 연다.
- 인기 입점관은 시트 안으로 옮겨 지도 위를 덜 가린다.

## 완료 기준

- 모바일에서 홈 버튼이 전역 탭·시트와 겹치지 않는다.
- 칩만으로 레이어 전환이 되고 독 카테고리 중복이 없다.
- 시트 peek→half에서 목록을 볼 수 있다.
- 데스크톱 지도 레이아웃과 기존 전역 하단 메뉴 동작이 변하지 않는다.

## 검증 결과

- 칩 통일 · 독 제거 · 시트 연결 반영.
- 린트·테스트·빌드 확인.
- 실제 모바일 기기에서 칩·시트·문의·전역 탭 최종 확인이 필요하다.
