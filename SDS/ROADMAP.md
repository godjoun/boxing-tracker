# SDS Roadmap

## 문서 정보

- 소유: SDS
- 독자: CEO, AI 팀, 개발자
- 읽는 시점: SDS 개선 우선순위를 정할 때

이 문서는 SDS 자체의 미래다. 회사가 만드는 제품의 로드맵은 `03_MANAGEMENT/ROADMAP.md`에 둔다.

## v0.5 — AI Secretary

조건: 프로젝트 상태, 작업 결과, 사용자 피드백의 원본과 갱신 주기가 정의되어 있을 것.

- 일일 상태 요약 형식
- 보류·위험·후속 작업의 근거 연결
- Management와 프로젝트 문서의 일관성 점검

## v0.6 — Health Check

조건: 각 점수의 데이터 출처, 산식, 허용 오차, 갱신 주기가 정의되어 있을 것.

- 문서·코드·보안·UX·브랜드의 측정 가능한 기준
- 근거 없는 점수 생성 금지
- 실제 상태와의 차이를 발견하는 경고

## v1.0 — Production Ready Core

조건: Core Workflow·Memory·Governance가 하나 이상의 실제 프로젝트에서 반복 검증되어 있을 것.

- `CORE/`: 모든 프로젝트에 필요한 안정된 운영 기능
- `EXTENSIONS/`: AI Coach, Inventory Manager 같은 제품별 선택 기능
