## 후보 패턴 — 다중 하단 고정 UI의 안전 영역 계산

- 관찰: 모바일 화면에 전역 Bottom Navigation과 화면 전용 고정 행동이 함께 있을 때, 화면 전용 레이아웃이 전역 메뉴 높이와 Safe Area를 제외하지 않으면 터치 대상이 가려질 수 있다.
- 증거: `docs/gym-mobile-navigation.md` (2026-08-02, 직접 사용자 피드백 1건)
- 적용 범위: 모바일 웹·앱에서 하단 고정 UI가 두 개 이상인 화면
- 한계: 현재 증거는 Boxing Tracker 짐 화면의 단일 사례이며, 실기기 최종 확인 전이다. 검증 전까지는 후보 패턴으로만 취급한다.
- 안전한 적용: 화면 전용 고정 요소의 높이·위치를 전역 Bottom Navigation 토큰과 Safe Area를 함께 사용해 계산한다.
- 마지막 검토: 2026-08-02
