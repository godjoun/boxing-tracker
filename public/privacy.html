PUNCH ERA

개인정보 처리방침

PUNCH ERA 운영자 [[OPERATOR_NAME]](이하 “운영자”)는 이용자의 개인정보를 필요한 범위에서만 처리합니다. 훈련 기록과 프로필 등 앱의 주요 데이터는 기본적으로 이용자의 기기에 저장되며, 모든 훈련 기록이 운영자 서버로 자동 전송되지는 않습니다.

1. 기기에 저장되는 정보

다음 정보는 브라우저의 localStorage, sessionStorage 등 이용자 기기의 저장 공간에 저장될 수 있습니다.

  • 링네임, 자기소개, 신체 설정, 경력, 지역, 소속 체육관 등 프로필 정보
  • 훈련 기록, 타이머 상태, 코스·기술 진행 상태, 저장한 훈련 설정과 앱 설정
  • 이용자가 선택한 프로필·홈·카드용 사진 데이터와 카드 편집 상태
  • 즐겨찾기, 최근 지도 검색 위치, 좌표, 검색 결과 등 위치·체육관 검색 캐시
  • 링네임 중복 확인을 위한 이 기기의 로컬 등록 정보

사진은 기기에 저장되지만 JSON 백업 파일에서는 제외됩니다. 훈련 기록, 사진 및 설정은 앱의 해당 삭제·초기화 기능을 사용하거나 브라우저 사이트 데이터를 삭제할 때 지워질 수 있습니다. 앱 삭제, 브라우저 데이터 삭제 또는 기기 변경 시에도 사라질 수 있으므로 필요한 훈련 기록은 JSON 백업으로 보관해야 합니다.

2. Supabase에 저장될 수 있는 정보

구분저장될 수 있는 정보처리 조건과 목적
EVENT v0 익명 인증 사용자 식별자, 행사 식별자, 참가자 표시 이름, 소속 체육관, 체중, 복싱 경력, 참석 상태, 스파링 요청 상태, 대진·순서·완료 상태 및 행사 운영 이력, 생성·수정 시각 이용자가 EVENT에 참가하거나 운영자가 행사를 관리할 때 참가 접수와 대진 운영을 위해 처리합니다.
링네임 인증된 사용자 식별자와 링네임 Supabase 링네임 기능이 활성화되고 서버 인증 사용자 식별자가 있는 환경에서 중복 확인과 등록을 위해 저장될 수 있습니다. 서버를 사용할 수 없거나 로컬 사용자로 이용하면 기기에만 등록됩니다.
제품 퍼널 통계 app_open, training_start, training_complete, training_card_create, profile_view 중 하나의 이벤트 이름과 발생 시각 운영 중인 프로덕션 앱의 핵심 이용 흐름을 집계합니다. 이 테이블에는 사용자 식별자, 이름, 연락처, 훈련 상세 또는 별도 payload를 저장하지 않습니다.

1차 출시에서는 체육관 입점·운영자 관리, 체육관 문의·채팅, 모임·교류·피드·DM, 라이벌·스파링 파트너 서버 기능 및 체육관 사진 공개 등록 기능을 제공하지 않습니다. 따라서 해당 기능을 통한 신규 개인정보 입력이나 서버 저장을 받지 않습니다.

EVENT 운영자는 행사 진행을 위해 참가 정보를 확인할 수 있고, 대진이 정해지면 상대 참가자에게 표시 이름, 소속 체육관, 체중 및 복싱 경력이 표시될 수 있습니다. 이 정보는 대진 운영 범위 밖의 외부 공개를 목적으로 하지 않습니다.

3. 위치와 체육관 검색

이용자가 위치 권한을 허용하면 브라우저가 현재 좌표와 정확도를 앱에 제공합니다. 현재 좌표로 도시명을 찾거나 주변 체육관을 검색할 때 좌표가 Photon 및 OpenStreetMap Overpass 계열 지도 서비스로 전송될 수 있습니다. 지역을 직접 검색하면 지역 검색어가 Photon으로 전송될 수 있습니다.

운영자의 Supabase 서버는 이용자의 실시간 위치를 상시 저장하지 않습니다. 최근 검색 위치와 일부 지도 검색 결과는 반복 요청을 줄이기 위해 브라우저에 저장됩니다. 체육관 검색 결과는 기본 30분 동안 재사용될 수 있고, 오류 시 최대 7일 이내의 기존 결과를 사용할 수 있습니다. 좌표 기반 도시 검색 캐시는 최대 7일 동안 재사용될 수 있습니다.

4. Vercel Analytics

서비스 이용 흐름과 페이지 통계를 확인하기 위해 Vercel Web Analytics를 사용합니다. 페이지 방문 정보와 app 내 행동 이벤트 이름, 운동 종류·기록 방식·카드 스타일·지도 화면 선택 상태·지역 검색어 등 해당 이벤트에 지정된 최소 속성이 처리될 수 있습니다. 운영자는 사용자 이름, 연락처 또는 메시지 본문을 custom event 속성으로 보내지 않으며, 이 정보는 이용자를 직접 식별하기 위한 목적으로 사용하지 않습니다.

5. 처리 목적

  • 홈복싱, 타이머, 코스·기술 훈련, 러닝, 개인 훈련 기록·프로필 및 로컬 백업 제공
  • EVENT v0 참가 접수, 대기 요청, 대진 편성 및 행사 운영
  • 링네임 중복 확인과 등록
  • 현재 위치 또는 지역 검색어를 이용한 체육관 지도 검색
  • 서비스 안정성, 품질 및 이용 흐름 분석

6. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 판매하지 않으며, 원칙적으로 본 방침에 적은 서비스 제공 범위를 벗어나 제3자에게 제공하지 않습니다. 다만 이용자가 별도로 동의한 경우 또는 법령에 근거한 요구가 있는 경우에는 예외로 합니다. EVENT 대진 운영 중 행사 운영자와 대진 상대에게 표시되는 정보의 범위는 제2조에 따릅니다.

8. 보유 기간

  • 기기 저장 정보: 이용자가 해당 데이터를 삭제하거나 브라우저 사이트 데이터를 삭제할 때까지 보관됩니다.
  • EVENT v0: 현재 자동 삭제 기능이 없습니다. 참가자 화면에서는 대기 요청을 취소하거나 참가 정보를 정정할 수 있지만 참가자·대진·운영 이력 전체를 직접 삭제할 수는 없습니다. 삭제 요청이 처리되거나 운영자가 행사 데이터를 수동 삭제할 때까지 보관될 수 있습니다.
  • 링네임: 이용자가 링네임을 변경하면 같은 사용자 행이 갱신될 수 있습니다. 현재 앱에는 서버 링네임 직접 삭제 화면이 없으며, 인증 사용자 삭제 또는 운영자의 삭제 요청 처리 시 삭제할 수 있습니다.
  • 제품 퍼널 통계: 개인 식별 정보가 없는 이벤트 이름과 시각만 저장합니다. 현재 자동 삭제 기능은 없으며 운영자가 집계 데이터 정리 또는 서비스 종료 시 삭제할 때까지 보관될 수 있습니다.

법령에 따라 별도 보존 의무가 생기는 경우에는 해당 기간 동안 분리하여 보관할 수 있습니다.

9. 파기 방법

기기 데이터는 앱의 해당 삭제·초기화 기능 또는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. 운영자가 서버 삭제 요청을 처리할 때에는 대상 데이터를 확인한 뒤 복구가 어렵도록 데이터베이스에서 삭제합니다. 법령상 보존해야 하는 정보가 있으면 다른 정보와 분리하여 보관한 후 보존 기간이 끝나면 파기합니다.

10. 이용자의 권리

이용자는 기기에 저장된 프로필과 훈련 기록을 앱에서 열람·정정·삭제하거나 JSON 파일로 내보낼 수 있습니다. EVENT 참가 정보는 행사 화면에서 열람·정정하고 대기 요청을 취소할 수 있습니다. EVENT 참가자 행·대진 운영 기록, 서버 링네임 및 기타 서버 데이터의 열람·삭제·처리정지는 아래 개인정보 문의처로 요청해야 합니다. 요청 시 대상 확인을 위해 행사명, 표시 이름 등 필요한 최소 정보를 요청할 수 있습니다.
