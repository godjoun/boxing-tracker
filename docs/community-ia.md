## 미래 커뮤니티 확장 루프

모든 기능은 이 순환 안의 역할만 가진다. 순환 밖 기능은 넣지 않는다.

```text
훈련
  → 기록
  → 교류
  → 프로필에 흔적
  → 신뢰
  → 새로운 교류
  → 다시 훈련
```

| 단계 | 제품에서의 역할 | 대표 화면 |
|------|-----------------|-----------|
| 훈련 | 오늘 벨을 울린다 | 홈 CTA · 훈련 · 타이머 |
| 기록 | 오늘을 남긴다 | 기록 · 완료 스틸컷 |
| 교류 | 사람·장소·일정으로 만난다 | 커뮤니티 허브·체육관·라이벌·모임 |
| 프로필에 흔적 | 완료만 증명으로 붙는다 | 프로필 「교류의 흔적」 |
| 신뢰 | 남이/내가 믿을 수 있는 복서 이력 | 프로필 표면 |
| 새로운 교류 | 신뢰가 다음 만남을 부른다 | 허브 · 라이벌 · 모임 |
| 다시 훈련 | 다음에 체육관 문을 연다 | 홈 · 훈련 |

**잠금 문장**

1. 교류의 끝은 커뮤니티가 아니라 **프로필**이다.
2. 허브는 **다음 교류**, 프로필은 **지난 증명**.
3. 신뢰가 **새로운 교류**를 열고, 교류가 다시 **훈련**으로 돌아온다.
4. SNS·공개 랭킹·배지 자랑은 이 루프에 없다.

### 보드 구조 채택 (옵션 1 · 목적 분리 강화 · 2026-08-04)

참고 보드는 **정보 구조·사용자 흐름만** 참고한다. WDC 비주얼 복제 금지.  
SNS·경쟁 UI는 Community Principle에 맞게 뺀다.

**한 화면 = 한 목적**

| 화면 | 목적 | 상단 제목 | 주 CTA (하나) | MVP |
|------|------|-----------|---------------|-----|
| 교류 피드 | 다음에 고를 만남 목록 | 교류 피드 | 모임 올리기 | ✅ |
| 교류 일정 | 예정·진행·완료 + D-day | 교류 일정 | 일정 만들기 | ✅ |
| 교류 제안 | 만남을 제안하는 입구 | 교류 제안 | 모임으로 제안하기 | ✅ 자리 (관↔관은 이후) |
| 교류 상세 | 한 일정의 조건·신청 | 교류 상세 | 참가 신청 / 대화 | ✅ (모임 보드) |
| 교류 기록 | 완료 증명 | — | — | 프로필 「교류의 흔적」 |

| 보드 요소 | 우리 |
|-----------|------|
| 좋아요·댓글 | 없음 |
| 뱃지 그리드 | 프로필 흔적으로 대체 |
| 랭킹 | 넣지 않음 |
| 피드+일정 한 화면 혼재 | 금지 — 목적 전환으로 분리 |

정보 계층 (모든 교류 화면):

```text
제목(목적)
  → 핵심 정보
  → 보조 정보
  → 세부(상세에서만)
```

카드 하나 = 의미 하나. 통계·버튼·설명을 한 카드에 몰지 않는다.

흐름:

```text
피드 확인 → 상세 → (제안/신청) → 일정 → 실시 → 기록(프로필 흔적) → 신뢰 → 새 교류
```

칩 `피드 · 교류 · 체육관 · 모임` (스파링·라이벌은 출시 숨김).  
기본 랜딩 = **피드** (카드 → 상세, FAB = 올리기).  
교류 칩 안 도구(좌→우): `제안 | 일정 | 뱃지 | 랭킹`.  
상세는 탭이 아니라 **피드 카드 → 상세**.  
뱃지·랭킹은 **카테고리 틀만** — 본기능은 프로필 흔적 / MVP 제외.

### Community Principle (잠금)

커뮤니티는 콘텐츠를 소비하는 공간이 아니라,  
**사람을 만나고, 함께 훈련하고, 그 결과가 프로필에 신뢰로 남는 공간**이다.

모든 커뮤니티 기능 판단:

> 이 기능이 **새로운 교류**를 만들거나, **프로필의 신뢰**를 높이는가?

좋아요 · 조회수 · 배지 경쟁보다 **실제 복싱 활동**을 우선한다.


## 한 줄 정의

커뮤니티 = **복싱 교류 플랫폼의 기반**.  
체육관 찾기가 목적이 아니라, 교류 → 프로필 신뢰 → 다시 교류를 돌리는 장이다.

## 용어

| 말 | 뜻 | 칩? |
|----|-----|-----|
| **교류** | (넓게) 플랫폼 목적·허브 / (좁게, 이후) 관↔관 | ✅ 허브 칩 |
| **체육관** | 장소·입점·문의·내 관 | ✅ |
| **라이벌** | 공개 카드·관심·1:1 | ❌ 출시 숨김 (Level 3) |
| **모임** | 사람 모집 일정 | ✅ |
| **스파링** | 만나서 치는 목적·행위 · 기록이 남는 것 | ❌ 칩 아님 |
| **나 / 개인 활동** | 신청·대화·카드·소속·예정 | ❌ 헤더 진입 |
| **교류의 흔적** | 프로필에 붙는 완료 이력 | 프로필 블록 |

## 출시 칩

```text
피드 | 교류 | 체육관 | 모임
```

- 찜 = 체육관 하위 필터 (칩 삭제)
- 기본 랜딩 = **피드**
- 스파링·라이벌 = `RELEASE_SCOPE.rivals = false`로 출시 숨김
- 관↔관 본구현 = 교류 안 자리만 · SQL/UI 본체는 출시 후 (`gym-exchange.md`)

## 정보 구조

```text
커뮤니티
├─ [게이트] 지역 → (선택) 내 체육관
├─ 교류 (허브)     다음에 할 교류 하나
│     ├─ 다가오는 모임
│     ├─ 스파링 가능한 라이벌 요약
│     ├─ 내 관 · 지역 한 줄
│     └─ (이후) 관↔관 자리
├─ 체육관          목록·지도·상세·문의·찜·입점
├─ 라이벌          카드·권역·관심·채팅
├─ 모임            올리기·신청·DM
└─ 나              내 관·카드·신청·대화·예정
         │
         ▼ 완료만
프로필 「교류의 흔적」
  · 참가한 교류·모임
  · 사진
  · 참가·소속 체육관
  · 스파링 기록·횟수·라운드
```

## 행동 → 프로필 흔적

| 행동 | 프로필 반영 조건 | 흔적 |
|------|------------------|------|
| 내 체육관 | 소속 지정 | 소속 관 |
| 체육관 문의 | — | 전면 흔적 **금지** (문의 ≠ 증명) |
| 모임 참가 | 참가 완료(단계적 출석) | 일정·장소·날짜 |
| 라이벌 상호 | 상호 관심 | 연결된 라이벌 (대화 내용 비공개) |
| 스파링 기록 | 라운드·(선택)사진 저장 | 횟수·라운드·사진 |
| 관↔관 (이후) | 완료 기록 | 상대 관·라운드·사진·횟수 |

완료만 올린다. 신청·관심만으로 자랑칸에 올리지 않는다.  
모임·스파링·관↔관은 **같은 이력 목록 + 유형 라벨**.

## 첫 사용자

1. 지역 없음 → 체육관 탭에서 지역만  
2. 내 관 없음 → 다닐 체육관 고르기  
3. 준비됨 → **피드** (기본 랜딩)

빈 SNS형 좋아요·공개 랭킹·배지 그리드·관↔관 제안 UI 없음.
