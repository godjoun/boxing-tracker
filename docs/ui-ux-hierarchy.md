# UI/UX 계층 개선 — 2026-08

> 소유: 프로젝트 `docs/`  
> 독자: 제품·디자인·프론트엔드 담당자  
> 사용하는 때: 기존 화면을 손볼 때, 새 기능을 추가하기 전

## 목적

기능을 늘리지 않고 기존 화면의 시선 흐름을 정리한다. 홈 첫 뷰에는 사용자가
지금 해야 할 행동 하나만 강하게 두고, 그 아래에서는 모든 기존 기능을 바로
찾고 이동할 수 있게 한다.

## 화면 목적

| 화면 | 목적 |
|---|---|
| 홈 | 사용자가 3초 안에 운동을 시작하고, 필요한 모든 기존 기능을 찾게 한다. |
| 링 | 사용자가 망설임 없이 라운드를 시작하게 한다. |
| 타이머 진행 | 사용자가 시간과 현재 라운드에 집중하게 한다. |
| 운동 완료 | 사용자가 오늘의 성취와 서사를 느끼게 한다. |
| 기록 | 사용자가 훈련을 빠르게 남기고 돌아보게 한다. |
| 명패 | 사용자가 자신의 성장과 복싱 시간을 증명하고 공유하게 한다. |
| 짐 | 사용자가 체육관 정보를 빠르게 확인하고 필요한 행동을 하게 한다. |
| 더보기 | 사용자가 필요한 도구와 기능을 빠르게 찾게 한다. |

## 화면별 결정

| 화면 | 첫 주인공 | 주 행동 | 뒤로 물린 정보 |
|---|---|---|---|
| 홈 | 오늘의 장면 + 전체 기능 | 레슨 열기 또는 훈련 시작 | 훈련 기록·통계·캘린더 |
| 링 | 오늘의 벨 | 기본 라운드 프리셋 시작 | 다른 프리셋·타이머 설정·링 메뉴 |
| 타이머 완료 | 완료 스틸컷 | 인증 카드 만들기 | 다시 시작·홈·기록 이동 |
| 짐 | 지도와 검색 | 지역 검색 | 분류 칩·결과 시트 보조 조작 |
| 명패 | 개인 명패 | 명패 공유 열기 | 라이벌 관리·누적 지표·훈련 증명 |
| 더보기 | 도구 목록 | 선택한 도구로 이동 | 백업 안내 |

## 표현 원칙

- 라이트는 흰 무대와 잉크 텍스트를 기본으로 한다.
- 다크는 오일 블랙과 버건디 나이트를 무대로 한다.
- 버건디 `#8A2E2E`는 시작·저장·문의 같은 사용자 행동에만 쓴다.
- 레벨·EXP는 성장의 뼈대이며, 일상 화면의 주인공이 아니다.
- 하단 내비는 현재 화면의 CTA보다 강하게 보이지 않는다.
- 홈의 전체 기능은 흔적 → 링 → 명패 → 바깥 → 도구 순으로 보인다.
- 홈은 오늘 훈련 → 전체 기능 → 내 훈련 기록의 세 구역을 충분한 여백으로
  구분한다. 구역 안의 작은 간격보다 구역 사이의 큰 여백을 우선한다.
- **버튼:** 화면당 메인 CTA는 하나만 버건디로 강조한다. 나머지는 Secondary
  (중립 테두리/배경) 또는 Text Button으로 낮춘다. 사용자가 “무엇을 눌러야
  하지?”라고 고민하지 않게 한다.

| 화면 | 메인 CTA | Secondary / Text |
|---|---|---|
| 홈 | 오늘 훈련 시작·레슨 열기 | 기능 타일, 인증 카드, 링에서 더 보기, 백업 |
| 링 | 기본 라운드 프리셋 | 다른 프리셋, 타이머 설정, 링 메뉴 |
| 운동 완료 | 인증 카드 만들기 | 다시 시작, 홈, 기록 |

## 수동 확인

- 375px와 721px 이상에서 첫 CTA와 하단 내비가 겹치지 않는다.
- 홈의 미훈련·훈련 완료·진행 중 타이머·레슨 상태가 기존 목적지로 이동한다.
- 홈에서 기록, 라운드, 기술, 신체, 콤보, 훈련 카드, 명패, 성장, 짐, 백업,
  테마, 튜토리얼을 모두 찾고 이동할 수 있다.
- 링의 기본 프리셋·기타 프리셋·설정 진입, 타이머 완료 후 카드 제작이 유지된다.
- 짐의 칩·핀·시트·상세·문의, 명패의 편집·스튜디오·라이벌 흐름이 유지된다.
