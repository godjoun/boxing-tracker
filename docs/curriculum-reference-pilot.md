# 커리큘럼 동작 참고 — 1차 촬영 파일럿 (3동작 · 6장)

> 상태: **촬영 가이드만** · UI 미구현 · 이미지 자산 미추가  
> 근거 감사: 4주 커리큘럼 동작 참고 자료 감사 (승인)  
> 범위 밖: 1-2, 리드 훅, 영상, 동작 참고 UI

이 문서는 DAY 1~3 기본기 **자체 촬영·제작**을 위한 체크리스트다.  
앱에 이미지를 넣거나 UI를 붙이기 전에, 여기서 정한 장면으로 찍고 지도자 검토를 받는다.

---

## 콘텐츠 원칙

- 인터넷 사진, 유튜브 캡처, 유명 선수 이미지를 사용하지 않는다.
- 실제 촬영은 **촬영 대상자의 사용 동의**를 받은 뒤 진행한다.
- 얼굴은 꼭 노출할 필요 없다 (모자·크롭·후면 각도 가능).
- 단색 배경과 **동일한 복장**으로 통일한다.
- 사람의 복싱 자세를 **AI 이미지로 생성**해 교육 자료로 쓰지 않는다.
- 풋워크 발자국 다이어그램은 **직접 제작** 가능하다.
- 모든 자세 설명은 공개 전에 **실제 복싱 지도자 검토**를 받는다.
- 「항상」, 「반드시 이 각도」처럼 개인차를 무시하는 단정 표현은 피한다.
- 표기는 **오른손잡이 기본 스탠스(오소독스)** 기준. 왼손잡이는 좌우를 반대로 적용한다.

### 권장 산출물 형식

- 확장자: `.webp` (문서의 파일명과 맞춤)
- 권장 보관 경로(추가 시): `public/curriculum/reference/` (아직 생성하지 않음)
- 가로·세로는 앱 카드에 맞게 **세로 또는 정사각** 중 하나로 시리즈 통일

## DAY 1 — 오른손잡이 기본 스탠스와 가드

세션: `w1-s1` · 「스탠스와 가드」  
표기: **오른손잡이 기본 스탠스(오소독스)**  
보조 문구: **왼손잡이는 좌우를 반대로 적용하세요.**

### 1) `stance-front.webp`

| 항목 | 내용 |
|------|------|
| 목적 | 오소독스 발 위치(왼발 앞·오른발 뒤)를 정면에서 한눈에 보이게 한다. |
| 카메라 방향 | 모델 정면, 허리~발 중심 (머리·얼굴은 잘려도 됨). |
| 반드시 보일 것 | 양발 위치, 발 너비(어깨보다 살짝 넓은 정도), 앞발·뒷발의 앞뒤 관계. |
| 한 줄 설명 | 왼발 앞, 오른발 뒤 — 어깨보다 살짝 넓은 발 너비. |
| 핵심 포인트 | ① 앞발·뒷발 대각 배치 ② 너비는 어깨보다 살짝 넓게 ③ 무게는 발바닥 전체에 고르게 |
| 흔한 실수 | ① 발이 일자로 너무 좁음 ② 앞발·뒷발이 거의 나란함 |
| 안전 | 미끄러운 바닥 피하기 · 무릎을 과도하게 고정하지 않기 |
| 지도자 검토 | 오소독스 발 각도·너비가 입문용으로 무난한지 · 단정적 카피와 충돌 없는지 |

### 2) `stance-side.webp`

| 항목 | 내용 |
|------|------|
| 목적 | 측면에서도 무게 중심과 무릎 굴곡이 보이게 한다. |
| 카메라 방향 | 모델 측면(리드 쪽 또는 반대 중 시리즈에서 하나 고정), 머리~발 전신 가능하나 하체 중심. |
| 반드시 보일 것 | 무릎의 부드러운 굴곡, 상체 기울기(과한 전경 없음), 양발의 앞뒤 간격. |
| 한 줄 설명 | 무릎을 부드럽게 굽히고, 무게를 발바닥 전체에 둔 측면. |
| 핵심 포인트 | ① 무릎 잠그지 않기 ② 무게 한쪽에만 쏠리지 않기 ③ 상체는 과도하게 숙이지 않기 |
| 흔한 실수 | ① 뒷꿈치만 들거나 앞꿈치만 버티기 ② 무릎이 안쪽으로 무너짐 |
| 안전 | 무릎·발목 통증이 있으면 각도·깊이를 줄이고 중단 |
| 지도자 검토 | 입문자에게 권할 굴곡 깊이가 적절한지 · 「완벽한 각도」로 읽히지 않는지 |

### 3) `guard-position.webp`

| 항목 | 내용 |
|------|------|
| 목적 | 손·팔꿈치·턱이 한 프레임에 보이는 기본 가드. |
| 카메라 방향 | 약간 사선 정면 또는 정면 — 양손과 팔꿈치, 턱 라인이 보이도록. |
| 반드시 보일 것 | 손 높이(볼·관자놀이 부근), 팔꿈치와 옆구리 간격, 턱을 과도하게 치켜들지 않은 상태. |
| 한 줄 설명 | 손은 볼 높이, 팔꿈치는 옆구리 가까이, 턱은 살짝 숙인 가드. |
| 핵심 포인트 | ① 양손 가드 높이 유지 ② 팔꿈치는 몸 쪽에 가깝게 ③ 턱을 열어두지 않기 |
| 흔한 실수 | ① 팔꿈치가 밖으로 벌어짐 ② 손이 너무 낮아 턱·얼굴이 열림 |
| 안전 | 어깨 힘을 과하게 주지 않기 · 호흡을 참지 않기 |
| 지도자 검토 | 홈 섀도우용 가드로 무난한지 · 체형별 손 높이 표현이 과하게 단정되지 않았는지 |

## DAY 2 — 잽 뻗기와 복귀

세션: `w1-s2` · 「잽 연습」  
기준: 오른손잡이(오소독스) **앞손(왼손) 잽**. 왼손잡이는 좌우 반대.

### 4) `jab-extension.webp`

| 항목 | 내용 |
|------|------|
| 목적 | 잽이 뻗어진 순간의 팔·어깨·가드 관계를 보여 준다. |
| 카메라 방향 | 사선 정면 또는 측면 — 뻗은 앞팔과 반대편 가드 손이 함께 보이게. |
| 반드시 보일 것 | 앞손의 신장, 반대 손의 남는 가드, 어깨가 과도하게만 나가지 않은 자세. |
| 한 줄 설명 | 앞손을 뻗되, 반대 손은 가드에 남긴 상태. |
| 핵심 포인트 | ① 힘은 약 70% 감각으로 ② 반대 손 가드 유지 ③ 턱 라인을 열어두지 않기 |
| 흔한 실수 | ① 친 뒤 손을 내린 채 멈춤(이 컷에서는 아직 복귀 전) ② 어깨만 내밀고 하체는 무너짐 |
| 안전 | 팔꿈치를 과신전하지 않기 · 손목이 꺾이지 않게 |
| 지도자 검토 | 섀도우용 신장·어깨 라인으로 무난한지 · 「항상 이렇게」로 읽히지 않는지 |

### 5) `jab-return.webp`

| 항목 | 내용 |
|------|------|
| 목적 | 잽 직후 **가드로 복귀한** 상태를 보여 준다 (뻗기와 짝). |
| 카메라 방향 | `jab-extension.webp`와 **동일 각도·동일 거리**로 짝 비교가 되게. |
| 반드시 보일 것 | 양손이 다시 가드 위치, 팔꿈치가 몸 쪽으로 돌아온 상태. |
| 한 줄 설명 | 뻗은 뒤 바로 양손이 가드로 돌아온 상태. |
| 핵심 포인트 | ① 뻗자마자 복귀 ② 가드 높이 회복 ③ 다음 동작을 위한 준비 |
| 흔한 실수 | ① 친 손이 허공·허리에 남음 ② 복귀하며 상체가 크게 열림 |
| 안전 | 빠르게 당기느라 어깨를 으쓱하지 않기 |
| 지도자 검토 | extension 컷과 쌍으로 비교 학습이 되는지 · 복귀 경로가 과하게 단정되지 않았는지 |

## DAY 3 — 기본 풋워크

세션: `w1-s3` · 「풋워크 입문」  
형식: **사람 사진 없이** 발자국 + 화살표 **직접 제작 다이어그램** 권장.

### 6) `footwork-directions.webp`

| 항목 | 내용 |
|------|------|
| 목적 | 앞 2보 · 뒤 2보 · 좌·우 1보 패턴을 한 장으로 이해하게 한다. |
| 제작 방향 | 위에서 내려다본(탑다운) 발자국 실루엣 + 화살표. 오소독스 기준 왼발·오른발 구분 표기. |
| 반드시 보일 것 | 앞 / 뒤 / 좌 / 우 네 방향 화살표와 「몇 보」 표기, 왼손잡이 안내 한 줄. |
| 한 줄 설명 | 앞 2 · 뒤 2 · 좌우 1 — 가드를 유지한 채 미끄러지듯. |
| 핵심 포인트 | ① 가드를 유지한 채 이동 ② 발이 꼬이지 않게 ③ 크게 점프하지 않고 미끄러지듯 |
| 흔한 실수 | ① 이동 중 발이 교차·꼬임 ② 스텝하며 가드가 풀림 |
| 안전 | 좁은 공간·미끄러운 바닥에서 큰 스텝 금지 · 균형 잃으면 멈춤 |
| 지도자 검토 | 보폭·방향 표기가 입문 드릴과 맞는지 · 개인차(보폭)를 허용하는 문구인지 |
