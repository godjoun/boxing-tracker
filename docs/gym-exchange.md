# 체육관 교류 (관↔관) — 설계 잠금

> **승인:** 2026-08-04 · 관↔관 스키마·화면 설계.  
> **상위 IA:** `docs/community-ia.md` (Vision Loop · 허브). 관↔관은 허브의 **이후 모듈**.  
> **착수:** 출시·실사용 피드백 후. 그 전 코드/SQL 금지.

## 잠금 요약

| # | 결정 |
|---|------|
| 1 | **출시 칩** = `체육관 · 라이벌 · 모임` (찜 칩 삭제 → 체육관 하위 필터) |
| 2 | **교류** = 관↔관만. **모임** = 사람 모집 (`dojo_exchange_*` 유지). 이름 혼용 금지 |
| 3 | 관↔관 본구현 = **Level 3 · 출시 후**. 출시 직전 범위에 넣지 않음 |
| 4 | 스키마 prefix = `dojo_gym_exchange_*` (+ `dojo_gym_members`). 기존 모임 테이블 덮어쓰지 않음 |
| 5 | 1단계 표면 = 제안·일정·완료 기록·프로필 흔적만. **피드·좋아요·배지·랭킹 제외** |

## 용어

| 말 | 뜻 | 데이터 |
|----|-----|--------|
| **교류** | 체육관 ↔ 체육관 | `dojo_gym_exchanges` 계열 (미구현) |
| **모임** | 사람 모집 일정 | `dojo_exchange_events` / `applies` |
| **라이벌** | 개인 1:1 | `dojo_sparring_*` |

## IA

```text
커뮤니티
├─ 체육관     지역 → 목록/지도 → 상세·문의·내 체육관  (찜=필터)
├─ 교류 ★L3  제안 → 수락 → 일정 → 완료 기록 → 프로필 흔적
├─ 라이벌     공개 카드 · 관심 · 채팅
└─ 모임       사람 모집 · 신청 · DM

넣지 않음: 피드 탭 · 배지 탭 · 랭킹 탭 · 대회 탭
```

- **출시:** `체육관 · 라이벌 · 모임`
- **목표 (교류 도입 후):** `체육관 · 교류 · 라이벌 · 모임`
- 카피(목표): 「체육관을 찾고, 관과 교류하고, 라이벌을 만난다.」

## 범위

### 출시 직전

- 칩 정리(찜 흡수)만 가능 — Level 1–2
- 입점·문의·모임·라이벌 안정화
- 관↔관 UI/테이블 **없음**

### Level 3 — 교류 1단계 MVP

| 살림 | 버림 / 후순위 |
|------|----------------|
| 제안 · 수락/거절 · 상태 | SNS형 피드 |
| 일정 목록 + D-day | 좋아요·댓글 |
| 완료: 라운드·사진·한 줄 후기 | 배지 그리드 |
| 프로필 완료 교류 흔적 | 공개 랭킹 · 대회 · 관 레벨업 |

**성공 정의:** 우리 관 ↔ 상대 관이 제안→수락→실시→완료되고, 결과가 프로필에 검증 흔적으로 남는다.

### 나중

피드 공유 · 배지 · 지역 랭킹 · 월간 미션 · Realtime · 관장 Auth 고도화

## 스키마 (미구현 · 설계만)

기존 `dojo_exchange_*`(모임) **무변경**.

| 테이블 | 역할 |
|--------|------|
| `dojo_gym_listings` | 1단계 gym 식별자 (기존). 이후 `dojo_gyms` 승격 가능 |
| `dojo_gym_members` | `gym_id` · `user_id` · `role` (`admin`\|`member`) |
| `dojo_gym_exchanges` | `gym_a_id` · `gym_b_id` · `status` · 일시·장소·노트 · `proposed_by_user_id` |
| `dojo_gym_exchange_schedules` | `start_at` · `end_at` · `type` · `rounds` · `participants_count` |
| `dojo_gym_exchange_records` | `total_rounds` · `review` · `photos` · `result` optional |
| `dojo_gym_exchange_participants` | `user_id` · `role` · `weight` |

- status: `pending` \| `accepted` \| `ongoing` \| `completed` \| `canceled`
- OSM 관은 참조만. 교류 주체 = 입점/등록 관
- 멤버(admin) 없는 관은 제안 불가. 입점 `applicant_actor_id` → 첫 admin 시드 가능
- RLS: Auth `user_id` + member role. anon 공개 write 금지
- `badges` / `userBadges` / feed — 1단계 스키마에 없음

## 프로필 신뢰 흔적

| 흔적 | 출시 | 교류 1단계 |
|------|------|------------|
| 훈련 라운드·연속·시간 | ✅ | ✅ |
| 내 체육관 | ✅ | ✅ |
| 라이벌 카드 | ✅ | ✅ |
| 완료 교류 N회 · 라운드 합 · 사진 · 후기 | — | ✅ |
| 배지·랭킹·좋아요 | ❌ | ❌ |

표시 톤: 「Mantle ↔ ○○ · 2026.08 · 16R」— 이력/스틸컷. 대시보드 숫자판 아님.
